# Tracker de Horas

Una aplicación de escritorio hecha en Python (con PySide6) para registro, visualización y gestion de horas.

## Funcionalidades

- Cargar horas manualmente
- Guardado de registros con fecha
- Visualización de registros
- Edición y eliminación de entradas
- Preparado para conexión futura a base de datos

## Requisitos

- Python 3.9+
- PySide6

Instalación de dependencias (con pip):

pip install -r requirements.txt
